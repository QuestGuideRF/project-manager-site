# Менеджер проектов

Веб-приложение для локального управления проектами. Работает в браузере без сервера, используя File System Access API и IndexedDB для хранения метаданных.

## Возможности

- ✅ Добавление проектов с выбором папки через File System Access API
- ✅ Автоматическое определение языков программирования
- ✅ Просмотр README.md проектов
- ✅ Дерево файлов проекта
- ✅ Поиск по названию, описанию и тегам
- ✅ Фильтрация по тегам
- ✅ Темная/светлая/системная тема
- ✅ Адаптивный дизайн
- ✅ Хранение данных в IndexedDB (локально в браузере)

## Требования

- Современный браузер с поддержкой:
  - File System Access API (Chrome 86+, Edge 86+)
  - IndexedDB
  - ES6+ JavaScript

## Использование

### Важно: Запуск через локальный сервер

**File System Access API работает только через HTTP/HTTPS протокол**, поэтому файл нельзя открывать напрямую через `file://`. Используйте один из способов:

#### Способ 1: Python (рекомендуется)
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```
Затем откройте в браузере: `http://localhost:8000`

#### Способ 2: Node.js
```bash
npx http-server -p 8000
```

## Особенности

- **File System Access API**: Позволяет выбирать папки и файлы напрямую из файловой системы
- **IndexedDB**: Все метаданные проектов хранятся локально в браузере
- **Автоматическое определение языков**: Анализирует расширения файлов в проекте
- **Поиск в реальном времени**: Мгновенный поиск по проектам
- **Множественная фильтрация**: Выбор нескольких тегов одновременно

## Примечания

- File System Access API работает только в безопасном контексте (HTTPS или localhost)
- Для работы с файлами требуется разрешение пользователя
- Данные хранятся локально в браузере и не синхронизируются между устройствами
